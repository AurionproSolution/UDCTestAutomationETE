# START HERE — Test Automation Agents Kit

**Version 1.0.0** | For team members new to these agents

You received a zip with everything needed to install **Test Automation Architect** and **Test Case Writer** in your Playwright repo.

## What is in this zip?

| File / folder | What it is |
|---------------|------------|
| **SETUP-GUIDE.md** | **Read this first** — full step-by-step setup |
| **ONBOARDING.md** | Short checklist (after setup) |
| **docs/AI-Test-Automation-Agents-Whitepaper.md** | How to use the agents daily |
| **install.ps1** / **install.sh** | Installs agents into your Playwright repo |
| **agents/** | The two AI agent definitions |
| **templates/automation-blueprint.md** | Template you fill in for your project |
| **examples/udc-blueprint.md** | Completed example (UDC reference) |

## Quick path (60 minutes)

1. Unzip this folder anywhere on your machine
2. Open **SETUP-GUIDE.md** and follow every step
3. When done, open Cursor → **Test Automation Architect** → run the verify prompt from the guide
